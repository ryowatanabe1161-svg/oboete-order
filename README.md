# おぼえてオーダー！ 〜ふーさんの森カフェ〜

▶ **遊ぶ：https://ryowatanabe1161-svg.github.io/oboete-order/**

ブラウザだけで遊べる、2〜6人用の **協力型・記憶パーティーゲーム（オンライン版）** です。
森のカフェの店長 **ふーさん🐻** のもとで、みんなでお客さんの注文をおぼえて、手札をなくしましょう。

> オリジナル作品です（タイトル・メニュー・文章・見た目はすべて独自のもの）。

## 遊び方（かんたん）
1. ホストが「部屋を作る」。4文字の部屋コード・招待URL・QRコードが出ます。
2. 友だちはURL／QRを開くか、コードを入力して参加（2〜6人）。
3. **おぼえる**：ホストの端末が注文（レベル×人数）を1つずつ全員の画面に表示します（読み上げあり／端末ごとにON/OFF）。メモは禁止！
4. 注文はシャッフルされ、全員に均等に配られます。自分の手札しか見えません。
5. **自分の番**：メニュー全体（111品）から注文を1つ宣言。
   - **ほかの誰か**がその注文を持っていれば成功：そのカードは場から消えます。
   - 誰も持っていない、または**実は自分だけが持っていた**場合は失敗、そのレベルは脱落します（手札は残り、ほかの人から当ててもらうことはできます）。
6. **クリア**：手札0枚の人が 2人なら1人／3〜4人なら2人／5〜6人なら3人 になったら成功。レベル7クリアで完全勝利！
7. **お助け**（1人1回。自分の番に使っても宣言は消費しません）
   - 🔤 だれかの手札の「最初の文字」を見る
   - 🔚 だれかの手札の「最後の文字」を見る
   - 🗑️ 自分の手札を1枚捨てる（最後の1枚は捨てられない／ロビーで変更可）

## ロビー設定（ホストのみ）
| 設定 | 選択肢 | 既定 |
|---|---|---|
| スタートするレベル | 1〜7 | 1 |
| 表示スピード | ゆっくり 3.5秒 / ふつう 2.5秒 / はやい 1.6秒 | ふつう |
| お助け | レベルごとに1回 / ゲーム中1回 | レベルごと |
| 最後の1枚を捨てる | 捨てられない / 捨ててもよい | 捨てられない |

## ゲームの中断（⋯メニュー）
- **ホスト**：「中断してロビーに戻る」（確認あり）。いまのゲームを終了して、全員を同じ部屋のロビーに戻します。部屋コード・接続中の参加者・設定はそのままなので、部屋を作り直さずに次のゲームを始められます。
- **参加者**：「ロビーに戻りたい」をホストに伝える（ホストの画面に表示）／「退出する」。ゲームを中断できるのはホストだけです。
- 中断後にホストが再読み込みしても「前回の部屋を再開する」で同じ部屋に戻れます。

## ファイル
- `index.html`（画面とCSS）、`app.js`（通信・画面）、`logic.js`（ルールとメニュー。Nodeでも動作）
- `config.js`：STUN/TURNの設定（TURNを追加すると厳しいNAT環境でもつながりやすくなります）
- `vendor/`：PeerJS 1.5.5（MIT）、qrcode-generator（MIT）を同梱
- `test/`：`logic.test.js`（ルールの単体テスト）、`e2e.js`・`e2e4.js`（Playwrightによる3人・4人の通し試験）、`stun-server.js`（試験用のローカルSTUN）

## しくみ
- PeerJS（WebRTC）によるP2P。**ホストのブラウザが審判**で、山札・全員の手札・判定を持ちます。
- 各参加者には「自分の手札」と「全員の枚数」だけが送られます。お助けの結果は使った本人にだけ届きます。全員の手札はレベル終了時にだけ公開されます。
- 切断しても、同じ端末または同じニックネームで入り直せば元の席に戻れます。ホストはページを再読み込みしても「部屋を再開」できます。

## テスト
※ テスト用ファイル（`test/`）はこの公開リポジトリには含まれていません。

```
node test/logic.test.js

python3 -m http.server 8766 &
node test/e2e.js && node test/e2e4.js
```
